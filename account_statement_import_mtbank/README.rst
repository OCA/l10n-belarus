This module allows you to import bank statements from MTBank (Belarus)
XML format into Odoo.

MTBank provides bank statements in a specific XML format through their
online banking system. This module parses that format and creates bank
statements with transactions in Odoo.

**Supported features:**

- Import bank statements from MTBank XML files
- Automatic currency detection (BYN, USD, EUR, etc.)
- Automatic bank account matching using Belarus IBAN
- Support for debit and credit transactions
- Balance validation (opening and closing balances)
- Multi-account statements support

Configuration
=============

**Bank Journal Configuration:**

Before importing statements, ensure your bank journal is properly
configured:

1. Go to **Accounting > Configuration > Journals**
2. Open your bank journal (or create a new one)
3. Set the **Bank Account Number** to your Belarus IBAN (e.g.,
   ``BY09MTBK30120001093300069943``)
4. Set the **Currency** to match your account currency (BYN, USD, EUR,
   etc.)
5. Ensure the **Bank Accounting Account** is set

The module will automatically match the imported statement to the
correct journal based on the IBAN account number.

Usage
=====

To import a bank statement:

1. Go to **Accounting > Dashboard**
2. Click on the **Import** button on your bank journal
3. Select the MTBank XML file downloaded from your online banking
4. Click **Import**

The module will automatically:

- Detect the MTBank XML format
- Extract the account number and currency
- Create bank statement(s) with transactions
- Match the journal based on the bank account number

**Note:** The MTBank XML format contains daily summaries with
debit/credit turnover totals rather than individual transaction details.
The import will create aggregated transaction lines for each day with
movements.

**Requirements:**

- Bank journal must be configured with the correct Belarus IBAN account
  number
- The ``l10n_by`` and ``l10n_by_bank`` modules must be installed for
  Belarus account validation
