**Bank Journal Configuration:**

Before importing statements, ensure your bank journal is properly configured:

1. Go to **Accounting > Configuration > Journals**
2. Open your bank journal (or create a new one)
3. Set the **Bank Account Number** to your Belarus IBAN (e.g., `BY09MTBK30120001093300069943`)
4. Set the **Currency** to match your account currency (BYN, USD, EUR, etc.)
5. Ensure the **Bank Accounting Account** is set

The module will automatically match the imported statement to the correct journal based on the IBAN account number.
