This module allows you to import bank statements from MTBank (Belarus) XML format into Odoo.

MTBank provides bank statements in a specific XML format through their online banking system. This module parses that format and creates bank statements with transactions in Odoo.

**Supported features:**
* Import bank statements from MTBank XML files
* Automatic currency detection (BYN, USD, EUR, etc.)
* Automatic bank account matching using Belarus IBAN
* Support for debit and credit transactions
* Balance validation (opening and closing balances)
* Multi-account statements support
